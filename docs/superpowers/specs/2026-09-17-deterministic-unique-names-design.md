# Детерминированная генерация уникальных имён

Дата: 2026-09-17

## Задача

Генерировать читаемые имена для ~50 млн сущностей так, чтобы вероятность дубля была
пренебрежимой, а вызывающий код мог разрешить случившийся дубль повторным вызовом с
номером попытки. Суффиксы-хэши и числовые счётчики внутри имени недопустимы.

## Исходное состояние

Текущий `generate()` берёт по случайному слову из каждого словаря через `mt_rand()`.
На дефолтной паре `adjectives + animals` это 427 420 различных имён (18,4 бита):
50 % шанс дубля наступает на 692 сущностях, а на 50 млн пространство исчерпывается
полностью — в среднем 117 сущностей на имя. Словари содержат повторы (adjectives:
1449 строк / 1204 уникальных, animals: 377 / 355), что дополнительно перекашивает
распределение: самое частое имя выпадает в 12 раз чаще редкого.

## Решение

`generate()` становится детерминированной функцией от ключа и номера попытки.

```php
public function generate(int|string|null $id = null, int $attempt = 0): string
```

- `int` — целочисленный ID
- `string` — UUID любой версии, ULID или произвольная строка; формат не парсится
- `null` — ключ берётся из `random_bytes(16)`, результат недетерминирован
- `attempt` — при одном `$id` разные попытки гарантированно дают разные имена

Тип входит в ключ: `generate(42)` и `generate('42')` — разные ключи и, как правило,
разные имена.

### Алгоритм

Имя — это число `x` в диапазоне `[0, N)`, где `N` — произведение размеров позиций.

1. **Ключ → стартовая позиция.** Ключ кодируется с префиксом типа (`i:`, `s:`, `r:`
   для случайного) и хэшируется sha256. Первые 8 байт с обнулённым старшим битом (PHP
   int знаковый, поэтому используем 63 бита) дают `x0 = h mod N`, следующие 8 байт —
   шаг `g`.
2. **Шаг.** `g = 1 + (h2 mod (N - 1))`; пока `gcd(g, N) != 1`, увеличиваем `g` на
   единицу (с заворотом на 1 при достижении `N`). Взаимная простота с модулем
   означает, что последовательность `x0, x0+g, x0+2g, ...` обходит весь диапазон без
   повторов.
   Вырожденный случай: при `N == 1` шаг не определён (деление на `N - 1`), единственный
   возможный индекс — `0`, поэтому любой `attempt > 0` даёт `RuntimeException`.
3. **Попытка.** `attempt = i` означает «i-й допустимый элемент этой последовательности».
   Вычисляется пошаговым сложением `x = (x + g) % N`, а не умножением — `i*g`
   переполнило бы 64-битный int.
4. **Декодирование.** Смешанная система счисления: для каждой позиции
   `idx = x % size`, затем `x = intdiv(x, size)`. Слово берётся по `idx`, применяется
   `ucfirst()`, позиции соединяются разделителем.
5. **Запрет повторов.** Если в имени встретились одинаковые слова, значение
   пропускается и берётся следующее в той же последовательности. Фильтр только
   отбрасывает элементы, поэтому гарантия различия попыток сохраняется.

Гарантия различия попыток — жёсткая, а не вероятностная: ретрай никогда не вернёт уже
выданное для этого ключа имя.

Стоимость вызова линейна по `attempt`: последовательность проходится шаг за шагом, без
умножения по модулю. При ретраях на нарушение уникального индекса `attempt` исчисляется
единицами, так что это не имеет значения на практике, но перебор тысяч попыток подряд
стоит заметного времени.

Распределение слегка неравномерно, поскольку `2^63 mod N != 0`. При `N ~ 3*10^12`
перекос порядка `10^-7` от вероятности — на порядки меньше устраняемого эффекта
дубликатов в словарях. Rejection sampling не применяется.

### Словари

Позиция задаётся одним словарём или массивом словарей, объединяемых в общий пул
(конкатенация в порядке перечисления, затем дедупликация с сохранением первого
вхождения). Дефолт:

```php
[
    ['adjectives', 'languages', 'colors'],
    ['adjectives', 'languages', 'colors'],
    'animals',
    'names',
]
```

Пул `adjectives ∪ languages ∪ colors` = 1328 слов (не 1353: 13 слов пересекаются между
adjectives и languages, 12 — между adjectives и colors). Пространство:
`1328 * 1328 * 355 * 4940 = 3,1*10^12` (41,5 бита) — около 404 ожидаемых коллизий на
50 млн сущностей, то есть один дубль на 124 тысячи.

Изменения в данных:

- `countries.php` и `star-wars.php` удаляются вместе с константами
  `DICTIONARY_COUNTRIES` и `DICTIONARY_STAR_WARS`
- все словари нормализуются к нижнему регистру и дедуплицируются: adjectives
  1449 → 1204, animals 377 → 355; в colors, languages и names повторов не было, но
  languages и names хранились с заглавной буквы, из-за чего `english` и `English` не
  схлопывались при объединении в пул и не считались повтором одного слова

Пулы считаются лениво и мемоизируются; кэш сбрасывается в `setDictionaries()` и
`addDictionary()`.

### Что удаляется из API

- `setSeed()`, `setSeedFromString()` и поле `$seed` — их роль играет `$id`, а
  глобальный `mt_srand()` портил RNG всему процессу
- `setShuffle()` — несовместим с детерминизмом и мутировал конфигурацию
- `setLength()` — длина равна числу позиций в `setDictionaries()`

Остаются: `setDictionaries()`, `addDictionary()`, `setSeparator()`, `getDictionaries()`.

Добавляется `getSpaceSize(): int` — размер пространства `N` для текущей конфигурации.
Он нужен и как публичная информация (сколько имён вообще доступно при выбранном наборе
позиций), и как точка, где выполняется проверка переполнения.

### Ошибки

| Условие | Исключение |
|---|---|
| `N` переполняет `PHP_INT_MAX` (проверка на каждом умножении) | `RuntimeException` с указанием предельного числа позиций |
| Подряд идущих пропусков больше 1000 — запрет повторов неразрешим | `RuntimeException` |
| `N == 1` и `attempt > 0` — пространство исчерпано | `RuntimeException` |
| Полный обход последовательности без нужного числа допустимых значений | `RuntimeException` |

Две из этих веток недостижимы с поставляемыми словарями и остаются защитой на случай
пользовательских наборов: `N == 1` требует словаря из одного слова, а неразрешимый
запрет повторов — больше позиций, чем слов в наименьшем пуле (52 у colors), тогда как
53 позиции переполняют `N` задолго до этого.
| `attempt < 0` | `InvalidArgumentException` |
| `attempt > 10000` | `RuntimeException` |
| Пустой список позиций или пустой пул | `RuntimeException` |
| Неизвестное имя словаря | `RuntimeException` |

## Тестирование

Главный тест — прямая проверка биективности на малом пространстве: конфигурация
`[['colors'], ['animals']]` даёт `N = 18 460`, что позволяет перебрать попытки по
всему диапазону и убедиться, что все имена различны и их ровно столько, сколько
разрешает фильтр повторов.

Остальное:

- один `$id` при повторных вызовах и на новом объекте даёт одно имя
- `generate(42)` и `generate('42')` дают разные имена
- `attempt` от 0 до 1000 на одном `$id` — все имена различны
- во всех сгенерированных именах слова попарно различны
- `generate()` без аргументов даёт разные имена; на 10 000 вызовов дубликатов не
  больше, чем предсказывает день рождения
- все словари без дубликатов и без пустых строк
- каждое исключение из таблицы выше

## Область применения

При 404 ожидаемых коллизиях на 50 млн вставок вызывающий код обязан ловить нарушение
уникального индекса и повторять вызов с `attempt + 1`. Пять позиций (`пул x3 + animals
+ names`, `4,1*10^15`) снижают ожидание до 0,3 коллизии, если ретраи нежелательны.
